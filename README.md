## 🛞 TyresStorage

 **TyresStorage** — это веб-приложение для автоматического и ручного управления 18 секциями стеллажа, в которых хранятся автомобильные шины. Приложение отправляет HTTP-команды на устройства (секции) с заданным временем вращения и периодичностью, обеспечивая соблюдение требований ГОСТ по хранению шин.

## 🚀 Основные возможности

- **Автоматический запуск** по расписанию (период задаётся в днях).
- **Ручной запуск** любой секции в любой момент.
- **Интуитивный веб-интерфейс** с крупными элементами, оптимизированный для сенсорных экранов 1024×768.
- **Включение/отключение** отдельных секций.
- **Пропуск запусков** при выключении устройства: при следующем включении система догоняет пропущенный запуск.
- **Хранение состояния** в JSON-файле (без БД).
- **Автозапуск** при включении Raspberry Pi (systemd + киоск-режим Chromium).

## 📦 Установка и запуск на Raspberry Pi

### 1. Публикация приложения

Опубликуйте проект как **самодостаточное** приложение для архитектуры `linux-arm` (или `linux-arm64`):

```bash
dotnet publish -c Release -r linux-arm --self-contained true -o ./publish
```

### 2. Копирование на Raspberry Pi

Скопируйте содержимое папки `publish` в `/home/pi/TyresStorage`:

```bash
scp -r ./publish/* pi@<IP-Pi>:/home/pi/TyresStorage/
```

### 3. Настройка прав и запуск

```bash
chmod +x /home/pi/TyresStorage/TyresStorage
cd /home/pi/TyresStorage
./TyresStorage
```

Приложение будет доступно по адресу `http://<IP-Pi>:5000`.

---

## ⚙️ Автозапуск через systemd

Создайте службу `/etc/systemd/system/tyresstorage.service`:

[Unit]
Description=TyresStorage Device Manager
After=network.target

[Service]
WorkingDirectory=/home/pi/TyresStorage
ExecStart=/home/pi/TyresStorage/TyresStorage
Restart=always
RestartSec=10
User=pi

[Install]
WantedBy=multi-user.target

Включите и запустите:

```bash
sudo systemctl enable tyresstorage.service
sudo systemctl start tyresstorage.service
```

## 🖥️ Киоск-режим (автозапуск браузера)

Создайте скрипт `/home/pi/kiosk.sh`:

```bash
#!/bin/bash
xset s noblank
xset s off
xset -dpms
unclutter -idle 0.5 -root &
chromium-browser --noerrdialogs --disable-infobars --kiosk http://localhost:5000
```

Сделайте его исполняемым и добавьте службу `kiosk.service` (аналогично systemd), чтобы браузер открывался при загрузке.

## 🧩 Настройка под сенсорный экран

- Все элементы управления увеличены для удобства пальцевого ввода.

- Кнопки `+`/`−` изменяют значения и отправляют запрос без перезагрузки страницы (AJAX).

- Поддерживается разрешение 1024×768.
