## 📦 Публикация и развертывание приложения на Raspberry Pi

## 1. Публикация в Visual Studio

1. Открой проект в Visual Studio.
2. В обозревателе решений кликни правой кнопкой по проекту → **Publish...**.
3. Если нет профиля, выбери **Folder** → укажи папку (например, `publish`).
4. Нажми **Edit** (или **Show all settings**), чтобы настроить:
   - **Target Framework**: `net8.0`
   - **Deployment Mode**: `Self-contained` (не требуется установка .NET Runtime на Raspberry Pi)
   - **Target Runtime**: выбери **linux-arm** или **linux-arm64** (зависит от твоей ОС на Pi; проверь командой `uname -m`)
   - **File Publish Options**: можно оставить по умолчанию.
5. Нажми **Save** → **Publish**.
6. После публикации в папке появятся все необходимые файлы, включая `TyresStorage` (исполняемый файл без расширения) и папку `wwwroot`.

---

## 2. Копирование на Raspberry Pi

### Способ 1: через SCP (из командной строки Windows)

- Открой командную строку (CMD) или PowerShell и выполни:
  
  ```bash
  scp -r C:\путь\к\папке\publish\* pi@<IP-адрес-Pi>:/home/pi/TyresStorage/
  ```

(Замени `C:\путь\к\папке\publish` на реальный путь, а `<IP-адрес-Pi>` на IP твоего Raspberry Pi, например `192.168.1.100`)

### Способ 2: через флешку

- Скопируй всю папку публикации на флешку.

- Подключи флешку к Raspberry Pi, она обычно монтируется в `/media/pi/`.

- Скопируй папку в домашнюю директорию:

bash

cp -r /media/pi/ИМЯ_ФЛЕШКИ/TyresStorage /home/pi/

---

## 3. Настройка прав и запуск

Подключись к Raspberry Pi по SSH или открой терминал на нём.

Перейди в папку с приложением:

bash

cd /home/pi/TyresStorage

Дай права на исполнение:

bash

chmod +x TyresStorage

Запусти вручную для проверки:

bash

./TyresStorage

Приложение должно запуститься и слушать порт `5000`. Открой браузер на Pi по адресу `http://localhost:5000` или на другом устройстве в сети по `http://<IP-Pi>:5000`.

Если всё работает, останови приложение (Ctrl+C).

---

## 4. Настройка автозапуска (опционально)

Если хочешь, чтобы приложение стартовало автоматически при включении 
Raspberry Pi, следуй шагам из инструкции по настройке systemd (создай 
службу `tyresstorage.service`подробнее смотри в deploy_final.md).

## 🧪 Проверка работоспособности

- Проверь, что в папке `Data` создался файл `devices.json` (при первом запуске).

- Проверь логи в консоли — они покажут работу планировщика.

- Убедись, что веб-интерфейс доступен и работает.

---

## 📌 Примечания

- Если ты публикуешь как `Self-contained`, то на Raspberry Pi **не нужно** устанавливать .NET Runtime.

- Если публикуешь как `Framework-dependent`, то нужно установить .NET 8 Runtime на Pi (`dotnet-install.sh`).

- Архитектуру (`linux-arm` или `linux-arm64`) можно определить командой на Pi:

bash

uname -m

- `armv7l` → `linux-arm`

- `aarch64` → `linux-arm64`
